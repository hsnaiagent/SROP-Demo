## Gotchas that cost time

- **The docs site's Ask AI assistant is broken** on this instance — canned refusal to every question.
  Read `private.docs.cohere.com` reference pages directly; they work.
- **Next.js 16.3 / React 19.2.** `AGENTS.md` warns of breaking changes vs. older conventions and points at
  `node_modules/next/dist/docs/`. Check route-handler signatures there before writing them.
- **North builder:** new nodes are inserted *above* the selected node and are **never auto-connected**.
  Drag connector-to-connector or publish validation rejects the graph.
- **Output template is not optional** in North — an empty one makes runs report "No output".
- **`/execute` only runs the live *published* version.**
- **The user's developer token expires 2026-08-11 10:47 UTC.** If the demo is after that, re-issue from
  `/developer` and re-run `npm run probe:auth`. An expired token looks exactly like the instance being down.
- **Never print the token.** It's in `.env.local` (gitignored). `north.mjs` redacts token-shaped strings
  out of error bodies; keep that behaviour if you refactor.
